# GitHub Module

Implementación del módulo GitHub sobre el CORE. Proporciona un cliente ligero para la API REST de GitHub y un repositorio de conveniencia que encapsula operaciones comunes (lectura/creación/actualización de archivos, ramas, commits y Pull Requests).

El módulo usa únicamente las abstracciones del CORE (Logger, ConfigProvider, BaseService, etc.) y no añade dependencias externas.
