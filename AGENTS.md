# AGENTS.md

## Objetivo

Este repositorio está diseñado para ser desarrollado principalmente por asistentes de IA.

## Reglas

- Mantener una arquitectura modular.
- No modificar código sin justificar el cambio.
- Documentar los cambios importantes.
- Evitar duplicar código.
- Mantener compatibilidad con TypeScript.
- Utilizar únicamente APIs oficiales.
- Priorizar la seguridad y el principio de mínimo privilegio.
- Generar commits claros y descriptivos.
