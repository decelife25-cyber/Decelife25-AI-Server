# Arquitectura de Decelife25 AI Server

## Objetivo

Decelife25 AI Server será un servidor que permitirá a asistentes de IA interactuar de forma segura con servicios externos mediante APIs oficiales.

## Servicios previstos

- GitHub
- Supabase
- Google Drive
- Google Calendar
- Google Sheets
- Gmail
- OpenAI
- Otros servicios futuros

## Principios

- Seguridad por defecto.
- Módulos independientes.
- APIs oficiales.
- Configuración mediante variables de entorno.
- Registro de todas las operaciones.
- Código mantenible y escalable.
